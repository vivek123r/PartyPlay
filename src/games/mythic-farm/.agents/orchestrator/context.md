# Context

## Project Overview
"MYTHIC FARM: SINGLE-PLAYER FARMVILLE & MAGIC ORCHARD" is a single-player 2D isometric/top-down farming simulation game integrated into the PartyPlay framework (`/home/viv/Projects/PartyPlay/src/games/mythic-farm`).

## Core Features
1. Dynamic Farming, Soil & Orchard Grid Engine
2. Insane Automation & Processing Workshop
3. Mythical Livestock & Animal Barns
4. Dynamic Market Economy & Expansion System
5. Single-Player Story Campaign & Arcade Integration
6. Audio, 60fps rendering, and clean build
